Thoughtful Features Built for Students

Every tool you need to stay organized without the overwhelm of bloated productivity suites.

⚡
Smart Free-Time Engine

Automatically identifies gaps between classes and recommends realistic tasks you can finish or make progress on during your breaks.

📄
Multi-Format Timetable Import

Import your schedule from PDF documents, Word (.docx) files, or screenshot images. Includes built-in OCR and a review modal before saving.

🌅
Tomorrow Planning & Rollover

Dedicate 2 minutes at the end of the day to roll over unfinished tasks to tomorrow and check off packed materials (backpack, charger, lab tools).

📌
Floating Widget & Tray Mode

Pin the widget to your desktop corner so your next class is always visible. Easily switch between standard mode and ultra-compact mode.

💾
Local SQLite Persistence

Zero reliance on third-party servers. Your timetable and to-dos are stored safely in an ACID-compliant local SQLite database with automated rolling backups.

🎨
Midnight Lavender & Light Theme

Tailored color palettes designed to minimize eye fatigue during long study sessions, with one-click toggle between Dark and Light mode.

🛡️ Security & Privacy First

Your Data Belongs to You. Period.

Hello 118:24 was designed from the ground up as a private, local-first application. We believe productivity tools should respect user sovereignty.

100% Offline by Design

Your tasks, class schedules, and daily notes are never uploaded to any remote server or cloud. Everything resides in your local operating system application data folder.

No Analytics or Telemetry

The application contains zero telemetry probes, zero tracking SDKs, and zero behavioral analytics. We collect zero personal data.

Electron Security Hardening

Built with context isolation enabled, node integration disabled in the renderer, strict Content Security Policy, renderer sandboxing, and IPC sender frame verification.

Automated Rolling Backups

The database layer maintains rolling snapshot backups before any migration or restore operation, protecting your schedule against write interruptions or corrupted imports.

Vulnerability Reporting: If you discover a security concern, please disclose it responsibly via GitHub Security Advisories.
